# منصة ثانوية مارز الإيمان الإدارية

منصة إدارية بملف واحد (HTML) لثانوية مارز الإيمان، تخدم المدير والوكيل والمعلمين:

- **الحضور والغياب:** تسجيل يومي + تعديل بأثر رجعي (غياب → غياب بعذر).
- **التقارير:** أكثر الأيام/الشُّعب/الصفوف غياباً، وتنبيهات الطلاب كثيري الغياب.
- **الطلاب:** إضافة، نقل بين الشُّعب، تعديل، وحذف.
- **المعلمون:** ربط كل معلم بموادّه (18 مادة) وشُعبه.
- **جدول الاختبارات:** لكل شعبة، مع نسخه لشُعب أخرى.
- **لجان الاختبارات:** تكوين يدوي يجمع شعبتين من صفّين مختلفين، بدون تكرار أي طالب، مع تصدير PDF وأداة تحقّق.

## التشغيل
افتح `index.html` في المتصفح مباشرة — يعمل بالحفظ المحلي فوراً.

## ربط قاعدة البيانات (Firebase)
لتصير البيانات مشتركة بين كل الأجهزة، عدّل `window.FIREBASE_CONFIG` أعلى ملف `index.html` بإعدادات مشروعك من Firebase Console، فعّل **Firestore**، ثم أعد الرفع.
